# Claude Chatbot - Python API Practice

## About
A beginner Python project to learn how
to communicate with Claude using the
Anthropic API.

## Features
- Sends user messages to Claude
- Supports multi-turn conversations
- Maintains conversation history
- Handles API errors
- Configures automatic retries

## Technologies
- Python
- Anthropic Python SDK
- python-dotenv

## Setup
1. Clone this repository.
2. Create a virtual environment.
3. Install dependencies:
   pip install anthropic python-dotenv
4. Create a .env file.
5. Add your API key:
   ANTHROPIC_API_KEY=your_api_key
6. Run:
   python main.py

## Note
A valid Anthropic API key and available API
credits are required for live API requests.
This project has not yet been tested against
the live Claude API.
